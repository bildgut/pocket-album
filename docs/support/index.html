Support

Pocket Album is a free hobby project. Here's where to get help:

Found a bug?
Open an issue on GitHub. The form asks for your app, iOS and Immich versions and what your API key may do. That's usually everything needed to reproduce it.
Question, idea or first impressions?
Join the discussions.
Security problem?
Please report it privately via GitHub's private reporting, not as a public issue.
Problem with your Immich server itself?
That belongs to the Immich project.

Common questions

“This isn't an Immich server.” Enter the address you use for the Immich web UI, for example https://photos.example.com. A trailing /api is fine too.

Buttons or sections are missing. Your API key probably lacks a permission. Settings shows what the key may do; the README lists all permissions.

My server is behind a login page (Authelia, Cloudflare Access). The app talks to Immich directly with an API key and can't pass such a login. Allow /api through for API-key requests, or use a VPN.

Please don't post your API key, server address or private photos in public threads.
